# Self-hosted typefaces

LearnSDLC's variable fonts are served from this folder, so rendering a page
makes no external font request:

- `outfit.woff2`: Outfit, the Latin variable-weight file of the Fontsource
  package `@fontsource-variable/outfit` (`outfit-latin-wght-normal.woff2`).
- `manrope.woff2`: Manrope, from `@fontsource-variable/manrope`
  (`manrope-latin-wght-normal.woff2`).
- `space-grotesk.woff2`: Space Grotesk, from
  `@fontsource-variable/space-grotesk` (`space-grotesk-latin-wght-normal.woff2`).

Each is distributed under the SIL Open Font License; the licence files sit
beside the fonts. The original family names are kept.
